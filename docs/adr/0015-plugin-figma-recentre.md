# 0015. Plugin Figma limité aux exceptions et au lien avec le code

- Statut : acceptée
- Date : 2026-11-06
- Référence : D15 dans [la vision produit](../vision.md)

## Décision

Le plugin Figma (v2) se limite à déclarer des exceptions et à relier un écran à son code.

## Alternative écartée

Une vérification complète des maquettes.

## Pourquoi

Figma Check designs vérifie déjà les maquettes ; se battre sur ce terrain est perdu d'avance.

## Ce qu'on accepte de perdre

La promesse d'un outil de design complet.
