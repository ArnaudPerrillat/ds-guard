# 0009. Contrat déduit du package, enrichi à la main

- Statut : acceptée
- Date : 2026-11-03
- Référence : D9 dans [la vision produit](../vision.md)

## Décision

Le contrat est généré depuis le package DS (types, tokens, manifeste Storybook) ; l'équipe DS ajoute les règles d'usage fines.

## Alternative écartée

Un contrat entièrement écrit par l'équipe DS.

## Pourquoi

Zéro configuration pour la première valeur ; les DS de taille moyenne n'ont pas d'équipe pour écrire leurs règles.

## Ce qu'on accepte de perdre

Les règles d'usage fines demandent quand même un effort de l'équipe DS.
