# 0004. Local d'abord, open source

- Statut : acceptée
- Date : 2026-11-03
- Référence : D4 dans [la vision produit](../vision.md)

## Décision

Le moteur, la CLI et l'Action sont open source et tournent sur la machine ou dans la CI du client.

## Alternative écartée

Un SaaS hébergé qui lit le code.

## Pourquoi

Le code des secteurs régulés (santé, finance) ne peut pas sortir ; l'open source rend le test possible sans achat.

## Ce qu'on accepte de perdre

Des revenus plus tardifs ; il faudra un vrai différenciateur payant.
