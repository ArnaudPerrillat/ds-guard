# 0006. React + TypeScript uniquement

- Statut : acceptée
- Date : 2026-11-03
- Référence : D6 dans [la vision produit](../vision.md)

## Décision

Le MVP ne prend en charge que React et TypeScript.

## Alternative écartée

Multi-framework dès le départ.

## Pourquoi

C'est là que se trouvent la plupart des DS outillés et des agents.

## Ce qu'on accepte de perdre

Les clients Vue et Angular, pour l'instant.
