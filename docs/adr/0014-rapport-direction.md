# 0014. Un rapport pour la direction dès le MVP

- Statut : acceptée
- Date : 2026-11-06
- Référence : D14 dans [la vision produit](../vision.md)

## Décision

Le MVP produit un rapport d'une page destiné à la direction : couverture expliquée, tendance, exceptions actives, décisions attendues.

## Alternative écartée

Un tableau de bord réservé à l'équipe DS.

## Pourquoi

Le principal frein à l'adoption est le manque de mandat (73 % des équipes en panne selon le rapport zeroheight 2026, chiffre de seconde main), qui se décide au-dessus de l'équipe DS.

## Ce qu'on accepte de perdre

Du temps de développement pris sur les règles.
